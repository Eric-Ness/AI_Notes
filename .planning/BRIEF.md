# AI Notes - Project Brief

## Vision
A curated repository of AI knowledge for friends and learners. Practical, approachable documentation covering prompt engineering, Claude Code workflows, and GitHub integration - everything needed to effectively use modern AI tools.

## Target Audience
- Friends curious about AI tools
- Developers new to AI-assisted coding
- Anyone wanting to learn prompt engineering and Claude Code
- People unfamiliar with Git/GitHub who want to collaborate

## Goals
1. **Teach** - Clear explanations with practical examples
2. **Reference** - Quick lookups for common tasks
3. **Share** - Easy to browse on GitHub, no setup required

## Current State
- Empty repository, fresh start
- Planning structure initialized

## Success Looks Like
- Someone new to AI can read through and understand core concepts
- Experienced users find useful reference material
- Content is organized logically and easy to navigate
- Examples are copy-pasteable and actually work

## Constraints
- Markdown only (renders nicely on GitHub)
- No external dependencies
- Beginner-friendly language
- Practical over theoretical

## Non-Goals
- Comprehensive API documentation (link to official docs instead)
- Covering every AI tool (focus on Claude/Claude Code)
- Academic depth (practical focus)
