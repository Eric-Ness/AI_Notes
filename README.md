# AI Notes

A practical guide to prompt engineering, Claude Code, and GitHub workflows. Written for friends and anyone looking to get started with AI-assisted development.

## Who This Is For

- Curious about AI tools but not sure where to start
- Developers wanting to use AI effectively in their workflow
- Complete beginners to Git/GitHub
- Anyone who wants practical examples, not theory

## Where to Start

**New to AI?** Start with [Prompt Engineering](docs/prompt-engineering/) - it's the foundation for everything else.

**Know AI but new to Claude Code?** Jump to [Claude Code](docs/claude-code/) for setup and usage.

**Never used Git?** [GitHub Basics](docs/github-basics/) will get you up to speed.
